<Update label="July 31, 2026" description="v1.7">

### Improvements
- **CC and BCC on agent-sent emails** — When an agent sends an email on your behalf, you can now ask it to CC or BCC additional recipients — including reply-to addressing.
- **OneDrive and SharePoint files work in Microsoft Teams** — Paste a OneDrive or SharePoint link in Teams, or pick a file from the file picker, and agents can see and work with it directly. No manual re-upload needed.
- **Long tasks now continue without interruption** — When an agent runs out of context mid-task, it now hands the work off to a fresh session automatically and picks up exactly where it left off. Your task keeps running; you never see an error.
- **Clearer messages when integrations hit errors** — When a connected app returns an error, agents now show a plain, actionable explanation instead of raw error text — so they can self-correct or tell you exactly what went wrong.

</Update>

<Update label="July 27, 2026" description="v1.6">

### New Features
- **Copy artifacts to your Knowledge library** — Files and documents your agents produce can now be saved directly to your shared Knowledge library in one click, so any agent can reference them in future tasks.

### Improvements
- **Read Excel files natively** — Agents can now open .xlsx and .xls files directly, no conversion needed. Drop a spreadsheet into any conversation and agents can read, analyze, and work with it right away.
- **Claude Sonnet 5 available** — Anthropic's latest model is now available to your agents, bringing improved reasoning and accuracy to complex tasks.

</Update>

<Update label="July 21, 2026" description="v1.5">

### Improvements
- **Transform videos with AI** — Pass a source video to the video generator to restyle, replace subjects, or reimagine the footage entirely.
- **Connect integrations over email, no browser required** — When you send a task via email that requires connecting a new integration, the agent now returns the OAuth or API-key link directly in its reply.

</Update>

<Update label="July 20, 2026" description="v1.4">

### New Features
- **Brand — set it once, every agent knows it** — Your organization's brand — colors, fonts, logo, and voice — is now captured automatically the first time you describe your company to an agent. Every agent that produces a document, image, or design reads your brand before it starts.
- **Reusable document templates** — Ask any agent to save a document layout as a reusable template and it gets saved to your shared Knowledge library. Pull it up by name anytime to generate a new document from the same structure.

### Improvements
- **Loops email campaigns can include images** — When building an email campaign through the Loops integration, agents can now upload images directly from your files.
- **Attach videos in Slack and on the web** — Drop an .mp4, .webm, or .mov file into any conversation and agents can transcribe, analyze, or build on it. Video uploads already worked in Teams; now they work everywhere.

</Update>

<Update label="July 14, 2026" description="v1.3">

### New Features
- **Agent scripts can now read and write Excel files** — Scripts running in the code-run tool can import SheetJS (xlsx) to parse spreadsheets, manipulate data, and generate Excel files.

### Improvements
- **Edit Knowledge files without leaving the page** — Markdown files in your shared Knowledge library now have an Edit button. Click it, make changes inline, and save — no more downloading, editing locally, and re-uploading.
- **Scheduled agent reports now arrive as content, not a file path** — Agents that write their output to a file and deliver it via $file now send the actual report to Slack, Teams, or email as intended.
- **Deleting a Knowledge file now asks for confirmation** — When you ask an agent to delete a shared Knowledge file, it pauses and shows a Delete/Cancel prompt before anything is removed.

</Update>

<Update label="July 13, 2026" description="v1.2">

### New Features
- **Knowledge** — Add it once. Every agent can use it. Knowledge is your organization's shared document library — pricing sheets, product docs, FAQs, and policies that every agent in your workspace can draw on whenever a task calls for them.

</Update>

<Update label="July 2, 2026" description="v1.1">

### New Features
- **Artifacts** — All agent outputs — documents, images, videos, and more — are now collected in one place. Access them from any page, filter by file type or by user, and find exactly what your agents produced without hunting through past conversations.

</Update>
